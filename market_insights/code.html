Actionable UX Directives for Engineering & Design

Directive 01 offline_pin

Enforce 'Optimistic UI' with Local SQLite Queues

With 48kbps baseline troughs and 950ms midday latency spikes in Nairobi and Kano, synchronous API blocking guarantees cart abandonment. Transactions must acknowledge locally first with visual pending stamps.

Target: Zero blocking loaders > 350ms
Directive 02 image_not_supported

Kill Heavy Hero Videos & Web Fonts

Prepaid data costs constitute 4.2% of weekly discretionary spend. Bundles that trigger large remote WebFont downloads or auto-play background media trigger immediate user uninstall rates exceeding 79%.

Rule: Strict < 9.5MB APK size budget
Directive 03 mic_external_on

Adopt Dual Modality (Voice Note & Icon Stamping)

Over 54% of cohort participants rely on voice memos and non-text visual icons. Replace multi-field text forms with speech-to-intent capture and explicit high-contrast pictorial categories.

Mandate: Voice-first fallback on every form
