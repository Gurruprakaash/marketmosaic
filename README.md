# MarketMosaic — Market Research Dashboard

MarketMosaic is a web-based market research dashboard UI designed to organize research projects, develop user personas, analyze inclusion, explore market insights, map user journeys, and present research reports.

## Features

- Overview Dashboard
- Research Projects
- Persona Studio
- Inclusion Audit
- Market Insights
- Journey Mapping
- Reports & Recommendations
- Settings
- Navigation between existing pages

## Pages

The project contains the following pages:

1. Overview Dashboard
2. Research Projects
3. Persona Studio
4. Inclusion Audit
5. Market Insights
6. Journey Mapping
7. Reports & Recommendations
8. Settings
